# Galgame narrative
Plan scene goal, emotional turn, player choices, branch convergence and ending. Keep route flags and character knowledge consistent. Separate narrative source from engine syntax. Use `tools/narrative.py` for sample JSON validation and Ren'Py export; it is not a full Ren'Py compiler.
